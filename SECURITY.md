# Security policy

## Reporting a vulnerability

Report vulnerabilities in any of the nine packages published from this
repository privately through GitHub:
[open a draft advisory](https://github.com/duskmoon-dev/duskmoon-bundler/security/advisories/new).

Please do not open a public issue for a suspected vulnerability.

This covers `duskmoon_hologram` and `duskmoon_quickbeam` as published here.
Both vendor upstream projects; report issues in the packages from this
repository here, and the maintainers coordinate with upstream where the cause
lies there.

Include the package and version, your Elixir and Erlang/OTP versions, what an
attacker can do, and the smallest reproduction you have.

## Supported versions

Fixes are released in the latest synchronized toolchain version only.
